## Goal

Build a market-making strategy that quotes continuously on a simulated exchange,
manages inventory risk, and stays profitable across changing volatility regimes.

## What we've done so far

- Set up an order-book replay harness from historical data.
- Implemented a baseline quoting strategy with fixed spreads.
- Started work on inventory-aware skewing.

## What's next

Parameter tuning, a latency model, and a writeup for the end-of-semester showcase.
